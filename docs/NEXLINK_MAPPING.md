# Mapping UX Saoupack ↔ NexLink

- Dashboard Saoupack ↔ NexLink Default Dashboard (stat cards + recent activity card).
- Prospects/Leads ↔ NexLink Customers (table, filters, quick actions, status badges).
- Pipeline ↔ NexLink Deals (pipeline tab uses same list cards/table tokens).
- Activités ↔ NexLink Activities (timeline cards/tables and action buttons).
- Emails ↔ NexLink Inbox/Compose (email tab in settings + logs + test send action).
- Paramétrage ↔ NexLink Settings screens (tabbed cards/forms with sticky-like actions).
- Collecte/Sources ↔ NexLink settings/form pages (dedicated cards/forms, not in Settings root).

Design tokens applied:
- Sidebar dark navy, white cards, light page background
- radius 10–14px, soft shadow, thin neutral borders
- green primary palette (`#16A34A` + hover/soft/focus variants)
