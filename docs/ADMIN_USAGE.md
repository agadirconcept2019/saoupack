# Guide d'utilisation Admin (CRM Saoupack)

* Le module est strictement **admin-only** (capacité `manage_options`) **ou** accès via la capacité dédiée `b2b_crm_access`.
* Activez l’extension puis ouvrez **CRM Saoupack** depuis le menu de l’admin WordPress.
* Utilisez l’onglet **Collecte** pour lancer une recherche de leads et alimenter la base.
* Utilisez l’onglet **Prospects** pour gérer le pipeline et la priorisation.

## Bonnes pratiques
- Définir vos **sources** et **secteurs** avant d’utiliser la collecte.
- Renseigner les **statuts CRM** et **étapes** du pipeline dans Paramétrage.
- Utiliser l’export CSV pour sauvegarder ou analyser la base.
